# H2 operations

Each SQL block below performs one operation. Submit it through `sqlx sql execute --datasource <id> --command "..."`. Repeat `--command` in the same invocation when operations need to share connection state.

Replace `table_name`, `column_name`, and `schema_name` with actual identifiers. H2 folds unquoted identifiers to upper case and accepts double-quoted identifiers, so `sqlx_values` and `"sqlx_values"` are different names.

`--type h2` runs on the JDBC worker and reaches H2 in two ways. Without a host it opens a local database file, which is what `--database <file>` or `--path <file>` selects and what it creates when the file does not exist; the default user is `sa`. With `--host` and `--port` (9092 by default) it connects to an H2 TCP server, where `--database` names the database relative to the server's base directory. H2 has no `--property` options here beyond the JDBC ones it accepts in the URL. Official links target the H2 documentation; the documentation root is https://h2database.com/html/main.html.

## 1. Identify the current connection

**Purpose:** Check the H2 version, the current user and the resolved database path before operating on a target. No placeholders need replacement.

```sql
SELECT H2VERSION() AS engine_version, CURRENT_USER() AS current_user, DATABASE_PATH() AS database_file;
```

**Result:** One row. An empty `database_file` means an in-memory database.

**Official documentation:** [H2VERSION](https://h2database.com/html/functions.html#h2version) · [DATABASE_PATH](https://h2database.com/html/functions.html#database_path)

## 2. List tables, views and sequences

**Purpose:** Discover queryable objects in a schema. Replace `schema_name`, or use `'PUBLIC'` for the default schema.

```sql
SELECT TABLE_TYPE, TABLE_NAME FROM INFORMATION_SCHEMA.TABLES
WHERE TABLE_SCHEMA = 'schema_name' ORDER BY TABLE_NAME;
```

**Result:** One row per object. H2 stores its catalog in `INFORMATION_SCHEMA`, which is read-only.

**Official documentation:** [INFORMATION_SCHEMA](https://h2database.com/html/features.html#information_schema)

## 3. Inspect a table

**Purpose:** Read column names, types and nullability of one table. Replace `table_name`.

```sql
SELECT COLUMN_NAME, DATA_TYPE, IS_NULLABLE, COLUMN_DEFAULT FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_NAME = 'table_name' ORDER BY ORDINAL_POSITION;
```

**Result:** One row per column, in declaration order.

**Official documentation:** [INFORMATION_SCHEMA.COLUMNS](https://h2database.com/html/features.html#information_schema)

## 4. Read rows with a bound

**Purpose:** Read a page of rows without loading a whole table. Replace `table_name` and `column_name`.

```sql
SELECT column_name FROM table_name ORDER BY column_name LIMIT 100 OFFSET 0;
```

**Result:** Up to 100 rows. H2 accepts `LIMIT`/`OFFSET` and the standard `FETCH FIRST n ROWS ONLY` spelling.

**Official documentation:** [SELECT](https://h2database.com/html/commands.html#select)

## 5. Write rows

**Purpose:** Insert, update or delete rows. Replace `table_name` and `column_name`.

```sql
INSERT INTO table_name (column_name) VALUES ('value');
UPDATE table_name SET column_name = 'value' WHERE id = 1;
DELETE FROM table_name WHERE id = 1;
```

**Result:** The CLI prints the affected-row count as `affected`. The batch stops at the first error without rolling back earlier statements, because autocommit is on.

**Official documentation:** [INSERT](https://h2database.com/html/commands.html#insert) · [UPDATE](https://h2database.com/html/commands.html#update) · [DELETE](https://h2database.com/html/commands.html#delete)

## 6. Create or change a table

**Purpose:** Add a table, a column or a constraint. Replace `table_name`, `column_name`, and `index_name`.

```sql
CREATE TABLE IF NOT EXISTS table_name (id BIGINT PRIMARY KEY, column_name VARCHAR(100));
ALTER TABLE table_name ADD COLUMN extra DECIMAL(18,3);
CREATE INDEX IF NOT EXISTS index_name ON table_name (column_name);
```

**Result:** The statements succeed without rows. An embedded database writes its changes to the file immediately, and a second process cannot open the same file while the first holds it.

**Official documentation:** [CREATE TABLE](https://h2database.com/html/commands.html#create_table) · [ALTER TABLE](https://h2database.com/html/commands.html#alter_table)

## 7. Use H2's own features

**Purpose:** Reach values H2 computes that have no portable SQL spelling. No placeholders need replacement.

```sql
SELECT HASH('SHA-256', STRINGTOUTF8('text'), 256) AS digest,
       FORMATDATETIME(CURRENT_TIMESTAMP, 'yyyy-MM-dd HH:mm:ss') AS formatted;
```

**Result:** One row. H2 returns a byte array as Base64 in the CLI output, and its date formatting follows Java patterns.

**Official documentation:** [Functions](https://h2database.com/html/functions.html)

## 8. Check the database file

**Purpose:** Read integrity and space counters. No placeholders need replacement.

```sql
SELECT * FROM INFORMATION_SCHEMA.SETTINGS WHERE SETTING_NAME IN ('info.BUILD_ID', 'info.VERSION');
SELECT SETTING_NAME, SETTING_VALUE FROM INFORMATION_SCHEMA.SETTINGS WHERE SETTING_NAME LIKE 'info.%';
```

**Result:** One row per setting. `SHUTDOWN` closes the database cleanly after the batch, which an embedded file usually does not need.

**Official documentation:** [SETTINGS](https://h2database.com/html/features.html#information_schema) · [SHUTDOWN](https://h2database.com/html/commands.html#shutdown)

## 9. Keep one statement per `--command`

**Purpose:** Understand what happens when one argument carries more than one statement. No placeholders need replacement.

```sql
SELECT 1
```

**Result:** SQLX sends each `--command` as one statement and rejects an argument that carries several, because H2 runs them all but reports only the first result. Split the work into repeated `--command` arguments instead; they run on one connection in order, and the batch stops at the first error:

```sh
sqlx sql execute --datasource <id> --command "CREATE TABLE IF NOT EXISTS t (id BIGINT)" --command "INSERT INTO t VALUES (1)"
```
